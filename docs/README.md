# Documentação do Projeto PAP

Comece pela execução para rodar o projeto. Depois leia a arquitetura e as boas
práticas antes de mudar o código.

- [Execução](execucao.md): requisitos, instalação, banco, primeiro acesso,
  atualização e solução de problemas.
- [Arquitetura](arquitetura.md): camadas, autenticação, banco de dados, rotas
  da API e organização do frontend.
- [Boas práticas](boas-praticas.md): regras de código da API, das telas, dos
  testes, das decisões e do Git.

O design e o plano de cada funcionalidade ficam em `superpowers/specs/` e
`superpowers/plans/`.
